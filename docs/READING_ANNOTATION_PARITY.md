# 阅读标注学习闭环：旧新版功能对等审查

审查范围：阅读原文中的划词、高亮、笔记、词汇本连接、草稿恢复、Session 持久化和移动端选择。

明确不在本轮范围：题号导航、题目卡片展示方式、原文与题目布局。

## 已完成

| 能力 | 新版实现 | 状态 |
| --- | --- | --- |
| Windows 长难句数据校验 | 校验前将 UTF-8 BOM、CRLF 和 CR 归一化为仓库标准 UTF-8/LF，再核对冻结字节数和 SHA-256；真实内容变化仍会失败 | 完成 |
| 稳定文本定位 | 保存段落索引、原始偏移、选中文字、前后文；偏移失效时使用选中文字和前后文重新定位 | 完成 |
| 划词浮动工具栏 | 原文选择后显示“高亮、笔记、加入词汇本、取消” | 完成 |
| Highlight | 使用 CSS Custom Highlight API 显示；切换 Part 或刷新后从草稿恢复 | 完成 |
| Notes | 支持新建、查看、编辑和删除，笔记与选区绑定 | 完成 |
| 加入词汇本 | 直接调用现有词汇本接口，不创建第二套词汇数据 | 完成 |
| 自动来源 | 自动携带原句、test_id、Test 标题、Part 和段落编号 | 完成 |
| 本地草稿 | 标注使用 test_id 作为稳定键保存，并同步写入现有 `ielts-platform-draft:<test_id>:...` 考试草稿 | 完成 |
| 后端 Session | 交卷请求携带 annotations；服务端校验 Test、Part、偏移、长度和笔记内容后写入 Session 的 result_json | 完成 |
| 历史恢复 | 读取历史 Session 时恢复后端 annotations，并显示历史原句高亮和笔记面板 | 完成 |
| 旧标注迁移 | 旧版按 Test 标题和 Part 分散保存的数据会自动补齐 test_id 并迁移到新草稿 | 完成 |
| 移动端长按 | 同时监听 selectionchange、touchend、pointerup；窄屏工具栏和笔记编辑器固定在底部可触达区域 | 完成 |
| 自动测试 | 前端类型检查、结构回归、Next.js 构建、后端 Session/Windows 校验测试和完整 Pytest | 完成 |

## 迁移原则复核

- 没有复制旧版路由、hash 监听、DOM 版本补丁或第二套考试页面。
- 没有修改标准答案、判分、Band、题库或词汇稳定 ID。
- 标注字段只作为学习数据进入 Session，不参与判分。
- 相同 annotation ID 只保留更新时间较新的记录，避免本地和历史恢复产生重复。
- 历史 Session 的 Test 标题由服务端权威题库覆盖，客户端不能伪造来源标题。
